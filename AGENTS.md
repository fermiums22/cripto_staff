# Project instructions

Read `docs/SERVER.md` before connecting to the home server or deploying.

Never commit private keys, API credentials, server backups, or personal data.
Keep real trading disabled: public market data and local paper trading only.
Do not restart Nika or modify Home Assistant, TrueNAS, or VPN without a task requiring it.
Report implemented and verified behavior separately from planned features.
